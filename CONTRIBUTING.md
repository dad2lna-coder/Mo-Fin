# Contributing to MoFin

Thanks for wanting to help. MoFin is a Flutter application that targets Fire TV / Android TV, Web, and Roku (SceneGraph). This page covers how to submit changes.

## Before you start

- Check existing issues and PRs before building significant changes.
- Ensure your changes follow the existing project style and design patterns.

## Setting up

You need Flutter stable 3.47 or newer.

```bash
git clone https://github.com/dad2lna-coder/Mo-Fin.git
cd Mo-Fin
flutter pub get
```

## Making changes

- Match the surrounding code style and architecture.
- Verify `flutter analyze` passes and `flutter test` succeeds.
- Test on at least one target platform.
