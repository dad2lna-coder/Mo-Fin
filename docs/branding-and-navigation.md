# MoFin Branding & Navigation

MoFin features a customized visual identity and optimized navigation for living room TV environments.

## Visual Branding

- **MoFin Lockups & Marks**: Custom SVG visual identity assets used across login screens, the main navigation bar, settings, and the screensaver.
- **Custom Screensaver**: MoFin branded screensaver featuring dark and light theme logo variations.

## D-Pad Remote Navigation

MoFin is designed for living room TV devices (Fire TV, Android TV, Roku) operated with a standard directional pad (D-pad) remote control:

- **Focus Highlights**: High-contrast outline highlights and scale animations clearly indicate the currently focused interactive element (buttons, cards, menu items).
- **Safe Dialog Focus**: Destructive actions (such as Jellyfin item deletion) default initial focus to safe actions like **Cancel** so accidental remote presses do not trigger unintended modifications.
- **Side Panel & Top Navigation**: Quick sidebar drawer and top bar switching designed for minimal D-pad clicks.
